# Machine Learning Projects

This repository contains beginner machine learning projects completed using Python and Google Colab.

## Projects

### Titanic Survival Prediction
- Predicts passenger survival using machine learning.

### Iris Flower Classification
- Classifies Iris flowers into three species.

### Credit Card Fraud Detection
- Detects fraudulent credit card transactions.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab
